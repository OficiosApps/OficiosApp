# Oficios para Railway

Aplicación de servicios con clientes, profesionales, empresas, gestión CEO, presupuestos, mensajes y PWA.

Seguí [README_RAILWAY.md](README_RAILWAY.md) para configurar Railway, el ingreso Google y la instalación en iPhone.

- Node.js 24; SQLite y fotos privadas en /data.
- Dockerfile y railway.json incluidos.
- npm run build:railway compila; npm start inicia el servidor.
- npm run db:seed aplica migraciones y prepara configuración, sin usuarios de ejemplo.
- Copiar variables de .env.example a Railway; nunca subir secretos.
